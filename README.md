# Among Us 3D Online

Proyecto básico con:

- Node.js
- Express
- Socket.IO
- Three.js en el cliente
- Carpeta `public` para servir el juego
- Preparado para Render

## Ejecutar local

```bash
npm install
npm run dev
```

Luego abre:

```text
http://localhost:3000
```

## Subir a Render

1. Sube este proyecto a GitHub.
2. Crea un nuevo Web Service en Render.
3. Usa estos comandos:

```bash
Build Command: npm install
Start Command: npm start
```

4. Render usará automáticamente `process.env.PORT`.
